# GuildClerkWorkGame

冒険者ギルドの受付で働くゲームです。`index.html` をブラウザで開くと遊べます（1280×720 基準、マウス操作）。

## 現在の範囲
- 営業時間（6:00〜22:00、ゲーム内1時間＝現実30秒）のリアルタイム進行と一時停止（P / Esc）
- 受注対応待ち・進行中・終了対応待ちの6枠を切り替えながらの並行処理（数字キー1〜6でも切り替え可能）
- 受注の認可／却下（却下理由は当てはまるものをすべて選ぶ）
- クエストの結果判定（適否で決まり、負傷と幽霊になる人だけ抽選）
- 帰還後の手当（棚から品を出す・タグを貼る・書類にハンコ）
- 営業終了時の扱い（受注待ちは帰る、進行中は翌日に持ち越し、終了対応待ちは対応が終わるまで続行）と営業成績
- （第2段階）早朝の荷ほどき、深夜の支給品注文、日の区切りでのセーブ（「次の日へ」で保存、タイトルの「続きから」で再開）

- （第3段階）効果音（Web Audio で合成、右上の「音 入／切」で切り替え）、判定のハンコ・所持金の増減・場面の切り替わりの演出、夕方の明かり

- 属性と状態異常：クエストの「魔物」「場所」欄、冒険者の信仰（内部属性）、却下理由「属性の危険」、帰還時の状態異常（火傷・凍え・麻痺・毒）と対応する支給品4種
- 支給品棚は全種類あわせて30マス（ドラッグで並べ替えは早朝・深夜のみ）。届いた箱は保管（10箱まで）され、早朝・深夜の「品出し」で棚に並べる

## ファイル
- `js/data.js` … 調整用の数値（報酬・来訪間隔・在庫など）とデータ
- `js/game.js` … ゲーム本体
- `js/sound.js` … 効果音
- `img/` … ドット絵
  - `img/newGraphic(clerk)/` … 受付嬢（ゲームが使うのはこちら）。`clerk_eyeopen`（通常）、`clerk_blink_1`→`clerk_blink_2`（まばたき）、`clerk_happy`（1パーティへの対応がすべてミスなく終わったとき）、`clerk_sad`（ミスをしたとき）、`clerk_rest`（深夜）
  - `img/clerk_work.png`・`img/clerk_rest.png` は最初に生成した旧版（現在は未使用）
- `tools/` … ドット絵の生成スクリプト（`python3 tools/gen_sprites.py` など。Pillow が必要）
