# 新しい概要と職業：能力適性の前提（設計中）

これまでの「推奨職業」による概要と職業の単純なつながりを作り直し、「能力適性」で比べる。
クエスト難易度と冒険者ランクはほぼ撤廃し、「能力素の量／総量」に置き換える。
属性は撤廃しないが、全ての冒険者が種族や職業と無関係に信仰をランダムに持つ形ではなくなる（詳細は後で決める）。

## 能力適性と能力素
能力適性は最大4文字のアルファベットで表す。4つの軸があり、各軸の1つ分の情報を「能力素」と呼ぶ。

| 軸 | 一方 | 中央 | もう一方 |
|---|---|---|---|
| ① 作用軸 | 攻撃 A | 中庸 / | 回復 C |
| ② 性質軸 | 物理 P | 中庸 / | 魔法 M |
| ③ 反応軸 | 速度 S | 中庸 / | 防御 D |
| ④ 思考軸 | 技術 T | 中庸 / | 知識 K |

- ほぼ全ての職業は、①〜④の各軸について情報を持つ。
- 書き表すときは、中庸の能力素を省き、中庸でない能力素をアルファベットに置き換える。
  - 例：戦士（①攻撃 ②物理 ③中庸 ④中庸）→ `AP`
  - 例：弓使い（①中庸 ②中庸 ③速度 ④技術）→ `ST`

## 職業の段階
- 全ての職業に「月並」「熟練」「伝説級」の三段階がある。
- 同じ職業なら、熟練は月並より能力素が1つ多く、伝説級は熟練よりさらに1つ多い。
- 月並の能力素が1つから始まる職業を「平凡職業」、2つから始まる職業を「冒険職業」と呼ぶ。
- 職業の能力素は `[月並の内訳]/[熟練の内訳]` と書く。
  - 例：配達員 `S/ST`、操竜師 `AS/AST`
  - 伝説級は常に `[熟練の内訳]?` で生成するので、表記を省く。
- `?` の能力素は、冒険者の生成時に、すでにある能力素とは別の軸から、中庸以外を1つランダムに選んで埋める。`?` が複数並ぶときは左から順に埋める。
- 「全区域共通職業」「特定区域限定職業」の区分がある（内容は後で説明される）。

## クエストの難易度
| 難易度 | 要求能力素総量 |
|---|---|
| 初級 | 1 |
| 低級 | 3 |
| 中級 | 5 |
| 上級 | 7 |
| 超上級 | 9 |

- 各概要には、選ばれうる難易度を1〜2つずつ前もって決めておく。
- 生成時は難易度を最初に決め（初級3：低級4：中級4：上級3：超上級1）、その難易度に対応する概要の中から選ぶ。

## パーティの適否（ここまでで決まっている部分）
- 最低限、パーティ全員の能力素の総量が、クエストの要求能力素総量以上である必要がある（旧「人員不足」に代わる条件）。

## 冒険者の生成
- 同じパーティの中で職業は重複しない。
- 次の割合の目安を、なるべくすべて守る。
  - 全区域共通職業 3：特定区域限定職業 1
  - 平凡職業 2：冒険職業 5
  - 月並 9：熟練 5：伝説級 1
