# GuildClerkWorkGame

冒険者ギルドの受付で働くゲームです。`index.html` をブラウザで開くと遊べます（1280×720 基準、マウス操作）。

## 現在の範囲（第1段階）
- 営業時間（6:00〜22:00、ゲーム内1時間＝現実30秒）のリアルタイム進行と一時停止（P / Esc）
- 受注対応待ち・進行中・終了対応待ちの6枠を切り替えながらの並行処理（数字キー1〜6でも切り替え可能）
- 受注の認可／却下（却下理由は当てはまるものをすべて選ぶ）
- クエストの結果判定（適否で決まり、負傷と幽霊になる人だけ抽選）
- 帰還後の手当（棚から品を出す・タグを貼る・書類にハンコ）
- 営業終了時の扱い（受注待ちは帰る、進行中は翌日に持ち越し、終了対応待ちは対応が終わるまで続行）と営業成績
- 早朝・深夜（支給品の注文と受け取り）とセーブは第2段階で追加予定

## ファイル
- `js/data.js` … 調整用の数値（報酬・来訪間隔・在庫など）とデータ
- `js/game.js` … ゲーム本体
- `img/` … ドット絵。`clerk_work.png`（営業中）と `clerk_rest.png`（休憩）は直接手直しして差し替え可能
- `tools/` … ドット絵の生成スクリプト（`python3 tools/gen_sprites.py` など。Pillow が必要）
