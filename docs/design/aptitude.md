# 新しい概要と職業：能力適性の前提（設計中）

これまでの「推奨職業」による概要と職業の単純なつながりを作り直し、「能力適性」で比べる。
クエスト難易度と冒険者ランクはほぼ撤廃し、「能力素の量／総量」に置き換える。
属性は撤廃しないが、全ての冒険者が種族や職業と無関係に信仰をランダムに持つ形ではなくなる（詳細は後で決める）。

## 能力適性と能力素
能力適性は最大4文字のアルファベットで表す。4つの軸があり、各軸の1つ分の情報を「能力素」と呼ぶ。

| 軸 | 一方 | 中央 | もう一方 |
|---|---|---|---|
| ① 作用軸 | 攻撃 A | 中庸 _ | 回復 C |
| ② 性質軸 | 物理 P | 中庸 _ | 魔法 M |
| ③ 反応軸 | 速度 S | 中庸 _ | 防御 D |
| ④ 思考軸 | 技術 T | 中庸 _ | 知識 K |

- ほぼ全ての職業は、①〜④の各軸について情報を持つ。
- 中庸の記号は `_`（職業の表記の区切り `/` と混ざらないように）。
- 書き表すときは、中庸の能力素を省き、中庸でない能力素をアルファベットに置き換える。文字は軸の順（①→④）に並べる。
  - 例：戦士（①攻撃 ②物理 ③中庸 ④中庸）→ `AP`
  - 例：弓使い（①中庸 ②中庸 ③速度 ④技術）→ `ST`

## 職業の段階
- 全ての職業に「月並」「熟練」「伝説級」の三段階がある。
- 同じ職業なら、熟練は月並より能力素が1つ多く、伝説級は熟練よりさらに1つ多い。
- 月並の能力素が1つから始まる職業を「平凡職業」、2つから始まる職業を「冒険職業」と呼ぶ。
- 職業の能力素は `[月並の内訳]/[熟練の内訳]` と書く。
  - 例：配達員 `S/ST`、操竜師 `AS/AST`
  - 伝説級は常に `[熟練の内訳]?` で生成するので、表記を省く。
- `?` の能力素は、冒険者の生成時に、すでにある能力素とは別の軸から、中庸以外を1つランダムに選んで埋める。`?` が複数並ぶときは左から順に埋める。
- `?` を書くときは、読みやすさのために必ず末尾に置く（例：`AD?`、`SK?`）。
- `?` を具体的な能力素で埋めたあとは、埋めた文字も含めて軸の順に並べ替える（例：`AD?` の `?` を `M` で埋めると `AMD`）。
- 「全区域共通職業」「特定区域限定職業」の区分がある（内容は後で説明される）。

## クエストの難易度
| 難易度 | 要求能力素総量 |
|---|---|
| 初級 | 1 |
| 低級 | 3 |
| 中級 | 5 |
| 上級 | 7 |
| 超上級 | 9 |

- 各概要には、選ばれうる難易度を1〜2つずつ前もって決めておく。
- 生成時は難易度を最初に決め（初級3：低級4：中級4：上級3：超上級1）、その難易度に対応する概要の中から選ぶ。

## パーティの適否（ここまでで決まっている部分）
- 最低限、パーティ全員の能力素の総量が、クエストの要求能力素総量以上である必要がある（旧「人員不足」に代わる条件）。

## 冒険者の生成
- 同じパーティの中で職業は重複しない。
- 次の割合の目安を、なるべくすべて守る。ただし、ゲームが最優先にするのは「却下事項がいくつのパーティが何割出るか」の基準で、職業の割合はあくまで目安。
  - 全区域共通職業 3：特定区域限定職業 1
  - 平凡職業 2：冒険職業 5
  - 月並 9：熟練 5：伝説級 1
- 共通／限定と、平凡／冒険の割合は、どちらも職業を選んだ時点で決まる。両方を満たす方法は実装側で決めてよい。

## 職業の一覧
表記は `[月並]/[熟練]`。伝説級は `[熟練]?`。`A/A?/C/C?` のように4つ並ぶものは、`A/A?` と `C/C?` のどちらかの系統になる。

### 全区域共通職業
［平凡職業］
- 挑戦者 `A/A?/C/C?` … この世界では、いわゆる初心者冒険者のことを「挑戦者」と呼ぶ決まりがある。

［冒険職業］
- 勇者 `A?/A??` … 能力適性が常に `?` を持つ職業として、ほかの職業とは完全に同列ではなくなる。
- 戦士 `AP/AP?`
- 魔術師 `AM/AM?`
- 弓使い `ST/ST?`
- 義賊 `AS/AS?`
- 僧侶 `CM/CM?`
- 格闘家 `AD/AD?`
- 騎士 `PD/PD?`
- 旅人 `PS/PS?`
- 技術者 `DT/DT?`
- 商人 `SK/SK?`
- 学者 `DK/DK?`
- 調教師 `CK/CK?` … 調教の対象は、動物、魔法生物、魔物など、人間以外のあらゆるもの。ただし、人型であったり十分な知能を持つ魔物を調教対象とすることは全国的に禁じられている（倫理的な問題があることと、調教することがそもそも危険であるため）。
- 芸術家 `CT/CT?`
- 清掃員 `CS/CS?`
- アイドル `CD/CD?`

### 「王都フラムルーク」限定職業
［平凡職業］
- 公務員 `K/K?` … 主に「法律や規定の扱いを心得ている住人」のこと。エルク自身の職業はこれ。

［冒険職業］
- 冒険貴族 `PK/PK?/MK/MK?` … 貴族の身分を持ちながら、あえて自ら危険な冒険やクエスト等に身を投じる好事家の王子や令嬢など。

### 「カササギ九竜魁」限定職業
［平凡職業］
- 配達員 `S/ST`

［冒険職業］
- 操竜師 `AS/AST` … 騎乗用の竜の操縦やテイムに長けた職業。
- 空船乗り `MS/MST` … 工学技術と魔術の合わせ技で空を飛ぶ船を「空船」と呼び、空船乗りはその操縦士。船に乗っていない間は小型機械や銃器などを使う。

### 「アビスタル工業区画」限定職業
［平凡職業］
- 修理工 `T/PT`

［冒険職業］
- 鉱石掘り `CT/CPT` … 単なる炭鉱夫ではなく、鉱石を掘る技術を持ちながら冒険者としても過ごしている者。坑道での経験から毒に耐性を持つ（設定としてそうというだけで、ゲームに絡めるかは別）。
- 機械技師 `DT/PDT`

### 「地底集落トモシビ」限定職業
［平凡職業］
- 峠守 `D/DK` … 主にトモシビ内で、集落内に踏み入ろうとする不届き者を退ける仕事を担っている住人。

［冒険職業］
- 魔物猟師 `PD/PDK`
- 霊術師 `MD/MDK` … 一部の霊術師は、幽霊救助隊スカラベの設定にあるような「物理的接触が可能な霊体」に、自身の身体を一時的に変化させる術を持つ。

### 「マカコボクの里」限定職業
［平凡職業］
- 栽培師 `C/CM` … 花屋や農家に加え、原生樹なども含めた植物全般に関わる人。

［冒険職業］
- 警備兵 `CD/CMD`
- 樹力使い `CT/CMT` … 樹力電塔や原生樹の樹力調節を技術としてできるだけでなく、魔法的な手段を用いて樹力そのものを身体に宿して操る者も含む。

### 「クルミナ大図書館」限定職業
［平凡職業］
- 司書 `M/MK` … 「クルミナ大図書館」という区域名から転じて、この地に住み、この地に特有の情報の扱いについて学んだ人々。

［冒険職業］
- 記録士 `MS/MSK` … 一部のフィンメイジが他者に情報の記述を頼ってきた歴史から、魔術師の傍にいて情報の記録を担当する人。
- 戦闘魔術師 `AM/AMK` … 魔術師は全世界に冒険者として普及しているが、戦闘魔術師は特に戦闘に最適化された職業で、単体での強さや攻撃力において通常の魔術師とは一線を画す。

### 限定職業をゲームに持ち込む方向性（検討中）
今の設定では、エルクのギルドは常にルーリオン中央区にあって動かない。持ち込み方は次のどちらかに絞れる。
- エルクが他の区域の支店を担当する機会があるようにする。
- エルクの担当は変わらず、ギルドに来る冒険者の傾向が、何らかの理由で特定の区域からの来訪者に偏ることがあるようにする。

## 当面の扱い
- 冒険者の見た目は、設計とシステムの組み込みが終わったあとで、指示された手順に沿って段階的に作り直す。それまでは仮の見た目でよい。
- 概要と職業の作り直しに合わせて、今ある資料の表記（ランク欄など）は見直しになる。対応マニュアルは、仕様のすべてを一冊に収めるのが現実的でなくなるので、何らかの工夫が必要。
- 場所の設定にある「低級モンスター」「中級以上の魔物」のような魔物の格の表現は、今は判断しない。魔物を相手にするクエストは大抵一種類の魔物を参照するので、クエストの難易度が魔物の格を間接的に伝えている、と読める。
